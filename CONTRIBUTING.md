# Contributing to the SEO case study

Corrections to public SEO documentation are welcome as pull requests. Describe the change, the supporting source, and how it can be verified.

- Do not publish private client assets, website access credentials, or unpublished business data.
- Label planned improvements separately from implemented changes.
- Do not report SEO ranking, traffic, conversion or performance gains without dated, permission-cleared evidence.
- Do not add invented software automation, CI security badges, or production infrastructure claims to this documentation-only repository.
