# SEO and website rebuild evidence checklist

This repository describes a website redevelopment and SEO optimization project, not a verified search-ranking outcome.

## Collect with client authorization

- Before/after website screenshots with dates and context.
- Changes to site structure, navigation and mobile presentation.
- Representative product category landing pages and updated titles/meta descriptions.
- URL redirect and canonicalization checks.
- Google Search Console index coverage, impressions, clicks, CTR and average position, with a defined comparison window.
- Search queries and country/device filters, where they can be published without business-sensitive details.
- PageSpeed Insights / Core Web Vitals, with dates and clear measurement context.

## Measurement rules

State baseline and comparison periods; avoid claiming top search positions without dated, query-specific evidence. Separate work **implemented on the live website** from proposals in the action plan. No traffic, revenue, or conversion uplift is established by this repository alone.

Client permission is required before publishing proprietary analytics, private WordPress configuration, internal screenshots or customer information.
