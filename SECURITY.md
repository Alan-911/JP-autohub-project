# Security and privacy note

This repository is a public **website rebuild and SEO case study**, not a copy of the live WordPress/WooCommerce installation or a security assessment of that installation.

Report any potentially sensitive exposure **privately** to the project maintainer through the contact information on their GitHub profile. Never post credentials, customer information, Search Console exports, or reproduction steps containing secrets in public issues.

The repository must not contain WordPress admin credentials, hosting tokens, customer data, payment information, proprietary theme/plugin code, or private analytics reports.

The live site owner manages actual website security, access controls, updates, backups, plugins and privacy compliance; this public repository does not independently verify those controls.
